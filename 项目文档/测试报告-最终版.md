**问题**: `alert()` 字符串没闭合，导致编译错误
**修复**: 将换行符改为 `\n`
**状态**: ✅ 已修复

### 2. AddNodeDialog.vue 重复定义
**问题**: `availableNodes` 定义了两次，有未使用的函数
**修复**: 删除重复代码和未使用的函数
**状态**: ✅ 已修复

### 3. AddNodeDialog.vue 缺少导入
**问题**: 使用了 `watch` 但没有导入
**修复**: 添加 `import { ref, computed, watch } from 'vue'`
**状态**: ✅ 已修复
