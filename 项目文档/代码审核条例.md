# 第二阶段代码审核条例

## 一、总体要求

### 1.1 审核原则
- **代码质量**：代码必须清晰、简洁、可维护
- **功能完整性**：所有功能必须完整实现
- **性能要求**：代码必须高效，无明显性能瓶颈
- **安全性**：代码必须安全，无明显安全漏洞
- **可维护性**：代码必须易于维护和扩展

---

## 二、代码质量审核

### 2.1 代码规范

#### 2.1.1 命名规范
**要求**：
- ✅ 变量、函数、类使用驼峰命名法（camelCase）
- ✅ 常量使用大写下划线命名法（UPPER_SNAKE_CASE）
- ✅ 组件文件名使用PascalCase
- ✅ 工具函数文件名使用camelCase

**示例**：
```javascript
// ✅ 正确
const userName = '张三'
function calculateAge() {}
const MAX_NODES = 1000

// ❌ 错误
const username = '张三'
function calculate_age() {}
const maxNodes = 1000
```

#### 2.1.2 文件组织
**要求**：
- ✅ 单一职责原则：每个文件只做一件事
- ✅ 文件命名清晰表达内容
- ✅ 组件文件包含template、script、style
- ✅ 工具文件不依赖业务逻辑

**示例**：
```
✅ 正确：
- TreePanel.vue（组件）
- TreeNode.vue（组件）
- helpers.js（工具）
- validators.js（工具）

❌ 错误：
- components.js（混合多个组件）
- utils.js（混合多个工具）
```

#### 2.1.3 注释规范
**要求**：
- ✅ 复杂逻辑必须添加注释
- ✅ 公开函数必须有JSDoc注释
- ✅ TODO标记必须说明原因和计划
- ✅ 注释语言与代码语言一致

**示例**：
```javascript
// ✅ 正确
/**
 * 根据ID查找节点
 * @param {string} id - 节点ID
 * @returns {Object|null} 节点对象或null
 */
function findNodeById(id) {
  return familyData.value.find(node => node.id === id)
}

// ❌ 错误
function findNodeById(id) {
  // 查找节点
  return familyData.value.find(node => node.id === id)
}
```

### 2.2 代码风格

#### 2.2.1 缩进和空格
**要求**：
- ✅ 使用2空格缩进
- ✅ 操作符前后加空格
- ✅ 函数参数之间加空格
- ✅ 对象和数组键值对之间加空格

**示例**：
```javascript
// ✅ 正确
const user = {
  id: '1',
  name: '张三',
  age: 30
}

function getUser(id) {
  return users.find(u => u.id === id)
}

const user = {id: '1',name: '张三',age: 30}
function getUser(id) {return users.find(u => u.id === id)}
```

#### 2.2.2 语句结束
**要求**：
- ✅ 每条语句必须以分号结束
- ✅ 不要省略分号

**示例**：
```javascript
// ✅ 正确
const name = '张三';
console.log(name);

// ❌ 错误
const name = '张三'
console.log(name)
```

#### 2.2.3 字符串
**要求**：
- ✅ 使用单引号或双引号，保持一致
- ✅ 长字符串使用模板字符串
- ✅ 避免字符串拼接

**示例**：
```javascript
// ✅ 正确
const message = `欢迎用户：${name}`

// ❌ 错误
const message = '欢迎用户：' + name
```

### 2.3 错误处理

#### 2.3.1 异步错误处理
**要求**：
- ✅ 所有异步操作必须使用try-catch
- ✅ 错误必须被捕获并处理
- ✅ 错误信息必须清晰

**示例**：
```javascript
// ✅ 正确
async function loadData() {
  try {
    const data = await DataService.loadData()
    return data
  } catch (error) {
    console.error('加载数据失败:', error)
    return []
  }
}

// ❌ 错误
async function loadData() {
  return await DataService.loadData()
}
```

#### 2.3.2 空值检查
**要求**：
- ✅ 所有外部输入必须验证
- ✅ 所有异步操作必须检查返回值
- ✅ 避免直接访问可能为null的属性

**示例**：
```javascript
// ✅ 正确
function getNode(id) {
  const node = dataStore.findNodeById(id)
  if (!node) {
    console.error('节点不存在:', id)
    return null
  }
  return node
}

// ❌ 错误
function getNode(id) {
  return dataStore.findNodeById(id).name
}
```

### 2.5 可维护性

#### 2.5.1 函数复杂度
**要求**：
- ✅ 单个函数不超过50行
- ✅ 单个函数不超过5个参数
- ✅ 避免深层嵌套

**示例**：
```javascript
// ✅ 正确
function processNode(node) {
  const validation = validateNode(node)
  if (!validation.valid) {
    return { success: false, errors: validation.errors }
  }

  const result = saveNode(node)
  return result
}

// ❌ 错误
function processNode(node) {
  if (validateNode(node).valid) {
    if (saveNode(node).success) {
      if (sendNotification(node.id).success) {
        return { success: true }
      } else {
        return { success: false, message: '通知发送失败' }
      }
    } else {
      return { success: false, message: '保存失败' }
    }
  } else {
    return { success: false, errors: validateNode(node).errors }
  }
}
```

#### 2.5.2 代码复用
**要求**：
- ✅ 相似代码提取为函数
- ✅ 避免代码重复
- ✅ 使用工具函数

**示例**：
```javascript
// ✅ 正确
function formatDate(date) {
  return date.toLocaleDateString('zh-CN')
}

function formatDateTime(date) {
  return date.toLocaleString('zh-CN')
}

// ❌ 错误
function formatDate(date) {
  return date.toLocaleDateString('zh-CN')
}
function formatDateTime(date) {
  return date.toLocaleString('zh-CN', {
    year: 'numeric',
    month: '2-digit',
    day: '2-digit',
    hour: '2-digit',
    minute: '2-digit'
  })
}
```

## 五、Services审核

### 5.1 数据服务

```javascript
async function loadData() {

    request.onerror = () => reject(request.error)
  })
}

}
```

### 5.2 加密服务

#### 5.2.1 加密安全
**要求**：
- ✅ 使用强加密算法（AES-256）
- ✅ 使用强密钥派生（PBKDF2）
- ✅ 加密参数必须正确

**示例**：
```javascript
// ✅ 正确
async function deriveKey(password, salt) {
  const keyMaterial = await crypto.subtle.importKey(
    'raw',
    encoder.encode(password),
    { name: 'PBKDF2' },
    false,
    ['deriveKey']
  )

  return crypto.subtle.deriveKey(
    {
      name: 'PBKDF2',
      salt: encoder.encode(salt),
      iterations: 100000,
      hash: 'SHA-256'
    },
    keyMaterial,
    { name: 'AES-GCM', length: 256 },
    false,
    ['encrypt', 'decrypt']
  )
}

// ❌ 错误
async function deriveKey(password, salt) {
  return crypto.subtle.deriveKey(
    { name: 'AES-GCM' },
    password,
    password,
    ['encrypt']
  )
}
```

### 7.2 加密安全
**要求**：

```javascript
// ✅ 正确
async function hashPassword(password) {
  const encoder = new TextEncoder()
  const data = encoder.encode(password)
  const hash = await crypto.subtle.digest('SHA-256', data)
  const hashArray = Array.from(new Uint8Array(hash))
  return hashArray.map(b => b.toString(16).padStart(2, '0')).join('')
}

// ❌ 错误

}
```

## 八、面向对象原则审核

### 8.1 类设计原则

#### 8.1.1 单一职责原则
**要求**：
- ✅ 每个类只负责一个职责
- ✅ 类名清晰表达其职责
- ✅ 避免一个类承担多个职责

**示例**：
```
✅ 正确：
- DatabaseManager.js - 只负责数据库操作
- EncryptionManager.js - 只负责加密解密
- ValidationManager.js - 只负责数据验证
- NodeManager.js - 只负责节点管理
- VisualizationManager.js - 只负责可视化渲染

❌ 错误：
- DataManager.js - 混合了数据库、加密、验证等多种职责
```

#### 8.1.2 封装性
**要求**：
- ✅ 私有属性和方法使用#前缀
- ✅ 私有方法不能被外部访问
- ✅ 公开接口必须通过管理类暴露
- ✅ 避免直接暴露内部实现

**示例**：
```javascript
// ✅ 正确
export class DatabaseManager {
  #dbName = 'FamilyTreeDB'
  #db = null

  async open() {
    // 私有方法
    return new Promise((resolve, reject) => {
      const request = indexedDB.open(this.#dbName, this.#version)
      request.onsuccess = () => {
        this.#db = request.result
        resolve(this.#db)
      }
    })
  }

  async save(storeName, data) {
    // 公开方法
    await this.open()
    // 使用私有属性和内部方法
    return new Promise((resolve, reject) => {
      const transaction = this.#db.transaction([storeName], 'readwrite')
      // ...
    })
  }
}

// ❌ 错误
export class DatabaseManager {
  dbName = 'FamilyTreeDB'
  db = null

  open() {
    // 私有方法被暴露
    return new Promise((resolve, reject) => {
      const request = indexedDB.open(this.dbName, this.#version)
      request.onsuccess = () => {
        this.db = request.result
        resolve(this.#db)
      }
    })
  }

  // 直接暴露内部方法
  async _internalMethod() {
    // ...
  }
}
```

#### 8.1.3 接口设计
**要求**：
- ✅ 通过FamilyTreeManager暴露所有接口
- ✅ 公开方法必须有清晰的文档注释
- ✅ 方法参数和返回值必须明确
- ✅ 避免暴露过多的内部方法

**示例**：
```javascript
// ✅ 正确 - 通过管理类暴露接口
export class FamilyTreeManager {
  #databaseManager = null
  #encryptionManager = null

  constructor() {
    this.#databaseManager = new DatabaseManager()
    this.#encryptionManager = new EncryptionManager()
  }

  /**
   * 保存数据
   * @param {string} storeName
   * @param {Array} data
   * @returns {Promise<void>}
   */
  async saveDatabase(storeName, data) {
    await this.#databaseManager.save(storeName, data)
  }

  /**
   * 加载数据
   * @param {string} storeName
   * @returns {Promise<Array>}
   */
  async loadDatabase(storeName) {
    return await this.#databaseManager.load(storeName)
  }
}

// ❌ 错误 - 直接暴露内部管理类
export class FamilyTreeManager {
```

### 8.2 类结构规范

#### 8.2.1 类的组成
**要求**：
- ✅ 类必须包含私有属性
- ✅ 类必须包含私有方法
- ✅ 类必须包含公开方法
- ✅ 私有属性和方法以#前缀命名

**示例**：
```javascript
// ✅ 正确
export class DatabaseManager {
  #dbName = 'FamilyTreeDB'
  #version = 1
  #db = null

  async open() {

    return new Promise((resolve, reject) => {
      const request = indexedDB.open(this.#dbName, this.#version)
      request.onsuccess = () => {
        this.#db = request.result
        resolve(this.#db)
      }
    })
  }

  async save(storeName, data) {
    await this.open()
    // 使用私有属性
    return new Promise((resolve, reject) => {
      const transaction = this.#db.transaction([storeName], 'readwrite')
      // ...
    })
  }
}

// ❌ 错误 - 没有私有属性和方法
export class DatabaseManager {
  dbName = 'FamilyTreeDB'
  version = 1

  open() {
    // 直接使用属性
```

```javascript
    return Array.from(array, byte => byte.toString(16).padStart(2, '0')).join('')
  }

  /**

   * @private
   * @param {string} password
   * @param {string} salt
   * @returns {Promise<CryptoKey>}

  async #deriveKey(password, salt) {

  }
}

// ❌ 错误 - 私有方法被暴露
export class EncryptionManager {

    // ...

    // ...
```

### 8.3 类的依赖关系

#### 8.3.1 依赖注入
**要求**：
- ✅ 类之间通过构造函数注入依赖
- ✅ 避免类之间直接实例化
- ✅ 依赖关系必须清晰
- ✅ 避免循环依赖

**示例**：
```javascript
// ✅ 正确
export class NodeManager {
  #dataManager = null

  constructor(dataManager) {
    this.#dataManager = dataManager

export class NodeManager {
```

- ✅ 避免深层嵌套
