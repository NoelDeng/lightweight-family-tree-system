## 一、项目背景与目标

本项目开发一款基于 Vue 3 的轻量级本地化族谱可视化系统，实现族谱数据的数字化管理、可视化展示和交互式探索，满足家族文化传承的现代需求。

**核心目标**：通过现代扁平化圆角 UI 和动态交互体验，让用户轻松构建、查看和分享家族历史。

**关键约束**：纯前端运行，无服务端依赖，所有数据存储在浏览器本地，用户密码自主管理。

## 二、系统核心功能设计

### 2.1 数据模型

采用扁平化节点存储 + 运行时树组装的数据架构，每个成员节点包含以下字段：

```javascript
{
  id: "唯一标识",            // 字符串
  name: "姓名",              // 字符串
  gender: "male",            // 字符串：male / female
  fatherId: "父亲ID",        // 字符串，单亲
  motherId: "母亲ID",        // 字符串，单亲
  spouseIds: ["配偶1", "配偶2"], // 数组，多配偶支持
  birthDate: "2000-01-01",   // 字符串
  bio: "备注信息",           // 字符串
  generation: 1              // 数字
}
```

**关系维护规则**：
- 配偶关系双向存储：a 和 b 是配偶 → a.spouseIds 含 b，b.spouseIds 含 a
- 查找子节点：遍历所有节点，fatherId 或 motherId 等于当前节点 ID 即为子节点
- 支持多配偶：通过 spouseIds 数组实现

### 2.2 可视化渲染

基于 D3.js 7 Tree Layout 的家族树渲染方案：

- **布局算法**：`d3.tree()` 生成节点坐标，`d3.stratify()` 将扁平数据转为层级结构
- **连接线**：`d3.linkHorizontal()` 绘制父子关系曲线
- **交互**：节点点击高亮、画布缩放拖拽、动态根节点切换
- **D3 渲染优化**：requestAnimationFrame 驱动渲染、批量 DOM 更新、CSS transform 动画、RenderPerformanceMonitor 性能监控

### 2.3 数据管理

**左侧 TreePanel**：
- 递归树组件（TreeNode）层级展示族谱结构
- 支持节点展开/收起、查找定位、新增/编辑/删除
- 操作立即同步到 IndexedDB 并联动刷新可视化

**双向联动**：
- 点击 TreePanel 节点 → Visualization 对应节点高亮居中
- 点击 Visualization 节点 → TreePanel 展开到对应节点

**数据导入/导出**：
- 支持上传 JSON 格式族谱数据
- 支持导出 AES-256 加密备份文件

### 2.4 安全体系

| 环节 | 方案 |
|------|------|
| 访问控制 | 系统启动强制密码验证，SHA-256 哈希比对，不存明文 |
| 会话管理 | 登录后内存中保持会话，关闭页面即失效 |
| 数据加密 | AES-256-GCM 加密敏感字段（name、fatherId、motherId、bio 等） |
| 密钥派生 | PBKDF2 从用户密码派生加密密钥，密钥不落盘 |
| 密码修改 | 支持修改访问密码，自动用旧密钥解密、新密钥重新加密全部数据 |

### 2.5 用户界面

- **设计风格**：现代扁平化，全圆角处理
- **色彩方案**：深蓝色系主色调 + 暖灰色背景
- **图标库**：Font Awesome + Lucide Vue
- **响应式适配**：
  - 桌面（>1024px）：左右双栏布局
  - 平板（768px–1024px）：固定宽度 + 弹性布局
  - 移动端（<768px）：垂直堆叠布局

## 三、技术架构

### 3.1 技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| 核心框架 | Vue 3 (Composition API) | 响应式数据绑定、组件化 |
| 构建工具 | Vite 4 | 开发服务器与生产构建 |
| 状态管理 | Pinia 2 | 全局状态（auth / data / visualization） |
| 可视化 | D3.js 7 | 家族树 SVG 渲染 |
| 样式 | Tailwind CSS 3 | 实用优先的 CSS 框架 |
| 本地数据库 | IndexedDB | 浏览器原生大容量存储 |
| 加密 | Web Crypto API | AES-256-GCM + PBKDF2 |
| 虚拟滚动 | vue-virtual-scroller | 大数据量列表渲染 |
| 图标 | Font Awesome + Lucide Vue | UI 图标 |

### 3.2 分层架构

```
┌──────────────────────────────────────────────┐
│            Vue Components（UI 层）             │
│  Login / Main / TreePanel / Visualization     │
│  AddNodeDialog / ImportDialog / VirtualTree   │
└──────────────────┬───────────────────────────┘
                   │
┌──────────────────▼───────────────────────────┐
│           Pinia Stores（状态层）               │
│     auth.js  │  data.js  │  visualization.js  │
└──────────────────┬───────────────────────────┘
                   │
┌──────────────────▼───────────────────────────┐
│          Services（服务层）                     │
│  DataService / EncryptionService              │
│  ChunkLoader / ChunkStorage                   │
└──────────────────┬───────────────────────────┘
                   │
┌──────────────────▼───────────────────────────┐
│          Classes（业务逻辑层）                  │
│  FamilyTreeManager（总控）                     │
│  DatabaseManager / EncryptionManager           │
│  NodeManager / ValidationManager               │
│  VisualizationManager / AuthManager            │
│  DataManager / HelperManager                   │
└──────────────────┬───────────────────────────┘
                   │
┌──────────────────▼───────────────────────────┐
│          IndexedDB（数据层）                    │
│       family-tree-db                          │
└──────────────────────────────────────────────┘
```

### 3.3 数据流

```
用户操作 → Vue Component（事件处理）
             ↓ emit / action
         Pinia Store（状态更新）
             ↓ 调用
         Service / Class（业务逻辑 + 加密）
             ↓ 读写
         IndexedDB（持久化）
             ↓ 返回
         状态响应式更新 → UI 重新渲染
```

## 六、性能优化成果

| 优化项 | 方案 | 效果 |
|--------|------|------|
| 基础优化 | 防抖/节流/节点缓存/memoize/shallowRef | 100-1000 节点提升 30-50% |
| 虚拟滚动 | vue-virtual-scroller + VirtualTree | 1000+ 节点帧率 ≥ 60fps，内存 < 30MB |
| 节点懒加载 | ChunkLoader 分片 + 渐进式渲染 | 初始加载 < 200ms |
| D3 优化 | RAF / 批量 DOM / CSS Transform | 拖拽帧率 ≥ 60fps |
| Web Worker | 世代/布局计算移至 Worker 线程 | 主线程不阻塞，UI 始终流畅 |
| Service Worker | Cache First + Network First 策略 | 首次加载后可离线访问 |
| 分片存储 | ChunkStorage 分片读写 IndexedDB | 大数据量读写性能显著提升 |
