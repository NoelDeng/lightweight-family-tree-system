#### 2.5 优化数据加载
```javascript
const loadFamilyData = async () => {
  loading.value = true
  error.value = null

  try {
    const data = await dataStore.loadFamilyData()

    // 使用shallowRef优化大数组
    familyData.value = data || []

    if (!isRendering.value) {
      renderTree()
    }
  } catch (err) {
    error.value = err.message
    console.error('加载族谱数据失败:', err)
  } finally {
    loading.value = false
  }
}
```

**性能提升**:
- 直接赋值而非引用
- 减少响应式开销
- 避免不必要的重新渲染
