## 技术栈

- **核心框架**：Vue 3 (Composition API) + Vite
- **状态管理**：Pinia
- **可视化**：D3.js 7
- **样式**：Tailwind CSS
- **数据库**：IndexedDB
- **加密**：Web Crypto API
- **图标**：Font Awesome
- **类型检查**：TypeScript（可选）

## 开发工具推荐
- **编辑器**：VS Code
- **插件**：
  - Volar（Vue 3 支持）
  - Tailwind CSS IntelliSense
  - Pinia
- **包管理**：npm 或 pnpm

## 项目初始化命令
```bash
# 创建Vue3项目
npm create vue@latest

# 安装依赖
npm install

# 安装Tailwind CSS
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

# 安装D3.js
npm install d3

# 安装Pinia
npm install pinia

# 安装Font Awesome
npm install @fortawesome/fontawesome-free

# 安装其他依赖
npm install lucide-vue-next  # 图标库
npm install vue-router  # 路由（可选）
```
